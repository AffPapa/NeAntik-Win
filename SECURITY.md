# Security policy

## Supported versions

Only the latest preview release receives fixes. The current supported line is `0.1.x-preview`.

## Report a vulnerability responsibly

Do **not** open a public issue for a suspected vulnerability and do not attach `Data/`, browser
profiles, cookies, history, backups, databases, proxy endpoints, usernames, passwords, logs or
screenshots that contain them.

Before making this repository public, the owner must enable GitHub **Private vulnerability
reporting** in repository settings. Use that private GitHub channel to report a reproducible
issue with redacted steps, the app version, Windows version and impact.

Until a private reporting channel is enabled, keep vulnerability reports private and do not
publish sensitive proof-of-concept material.

## Scope

The application is local-first and has no telemetry endpoint. Its key security boundaries and
limits are documented in [SECURITY_AND_SCOPE.md](SECURITY_AND_SCOPE.md).
