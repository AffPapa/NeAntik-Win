## [0.2.1-preview] — 2026-10-11

**Статус:** portable preview, Windows x64. Проверенная ОС: Windows 11 Pro, build 26200.
**Browser core:** установленный Chrome/Edge; движок в ZIP не включён. Python включён.
**Совместимость:** SQLite schema 1 и nevision-profile-backup-v1 сохранены.

### Добавлено и улучшено

- Запуск браузера в фоне; три рабочих потока и ограниченная очередь. При закрытии менеджер
  дожидается завершения принятых операций и не завершает браузеры принудительно.
- Проверка Chromium lockfile учитывает профили, открытые до запуска менеджера.
- Обнаружение Chrome/Edge в пользовательских папках и Windows App Paths.
- Кнопка «Расширения» открывает штатную страницу расширений выбранного закрытого профиля.
  Для уже открытого профиля используется меню его браузера. Скрытой установки расширений нет.
- Ctrl+N — новый профиль; Ctrl+F — поиск; Escape — очистка поиска; Enter в списке — запуск;
  F5 — обновление. Действия профиля доступны и в небольшом окне с прокруткой.
- Скопированный пароль очищается через 30 секунд или при выходе, если содержимое буфера не
  изменилось. Это не очищает историю и облачную синхронизацию буфера Windows.

### Исправлено и безопасность

- Backup/restore и восстановление прерванных операций поддерживают длинные Windows-пути
  без изменения системного реестра. Ошибка найдена на невыпущенном кандидате 0.2.0.
- Запуск устаревшего/удалённого профиля и неожиданная смена назначенного proxy блокируются.
- Общая блокировка восстановления защищает активные операции от второго экземпляра менеджера.
- Усилена проверка ZIP: Windows reserved names, raw backslash/NUL, повторы без учёта регистра,
  конфликт файла/каталога, ссылки, специальные файлы и повторный manifest отвергаются.
- Backup явно обозначен как **незашифрованный ZIP с потенциальными cookies и сессиями**.
  Proxy-паролей в нём нет, но публиковать такой архив нельзя.
- IPv6 proxy форматируется корректно; небезопасный синтаксис host не принимается.
- SOCKS5 с логином/паролем не запускается: stock Chrome/Edge его не поддерживает. Для HTTP(S)
  логин и пароль вводятся в окне браузера вручную. Vault не равен автоматической авторизации.
- Изолированная fail-fast сборка, metadata версии EXE, runtime licenses, SHA-256 и manifest.

### Скачивание, обновление и откат

- [Portable ZIP](/downloads/NeVisionWin-portable-v0.2.1-preview.zip),
  [SHA-256](/downloads/NeVisionWin-portable-v0.2.1-preview.zip.sha256),
  [manifest](/downloads/NeVisionWin-portable-v0.2.1-preview.manifest.json).
- Закройте профили и NeVision. Сохраните приватную копию всей старой папки. Распакуйте новую
  версию в **новую доступную для записи папку**, скопируйте туда свою Data и проверьте запуск.
  Не перезаписывайте старую Data и не запускайте EXE непосредственно из ZIP.
- Для отката сохраните старую папку с её прежней Data. Chromium может менять собственную
  схему профиля — безопасное понижение версии browser core не гарантируется.

### Честные ограничения

- Сборка не подписана; checksum проверяет целостность, но не заменяет подпись издателя.
- Проверка proxy остаётся TCP-only: без проверки авторизации, туннеля и репутации IP.
- Fingerprint spoofing и обещаний прохождения антифрод-проверок нет.
- DPAPI и App-Bound encryption могут привязывать секреты/сессии к устройству и Windows-учётной
  записи. Переносимость файлов приложения не гарантирует переносимость авторизованных сессий.
- Windows 10, ARM64, все масштабы/мониторы и чужие proxy-провайдеры этим тестовым циклом не
  сертифицированы. Это preview, а не обещание отсутствия любых дефектов.

## [0.1.3-preview] — 2026-07-26

- **Статус:** Reliability & recovery preview для Windows 10/11.
- **Browser core:** не поставляется; используется установленный Google Chrome или Microsoft Edge.
- **Совместимость профилей:** совместимо с `0.1.2-preview`; схема данных и формат `nevision-profile-backup-v1` не менялись.
- **Backup / rollback:** каждый новый backup получает уникальное имя и создаётся атомарно; для отката используйте сохранённую portable-папку `0.1.2-preview`, а create/delete/restore возвращают рабочее состояние при ошибке.

### Добавлено

- Уникальные атомарные backups: существующий архив не перезаписывается частично, а новый файл получает отдельное имя.
- Backup, restore, profile health и TCP-проверка proxy перенесены в фоновые задачи, чтобы окно оставалось отзывчивым.

### Изменено

- Создание, удаление и восстановление профиля выполняются rollback-safe последовательностями: при ошибке операция возвращает своё рабочее состояние.
- Profile busy guard не допускает конкурентные изменяющие операции над одним профилем и явно показывает, что профиль занят.
- Форма Proxy Vault теперь держит заметку о защите пароля и кнопки «Сохранить proxy» / «Отмена» в пределах экрана при распространённом масштабе Windows 150%.

### Безопасность и границы

- Обновление не добавляет подмену fingerprint, обход антифрода, банов или автоматизацию аккаунтов.
- Local-first хранение и защита proxy-паролей Windows DPAPI сохранены; backup по-прежнему не включает proxy-секреты.

### Известные проблемы и ограничения

- В portable папку не включено browser core; на компьютере должен быть Chrome или Edge, либо задан путь к Chromium-браузеру.
- Проверка proxy подтверждает только доступность TCP-порта, а не учётные данные, репутацию IP или доступ к стороннему сайту.
- Сборка не подписана сертификатом кода: Windows SmartScreen может показать предупреждение до появления подписи.

## [0.1.0-preview] — 2026-07-25

**Статус:** portable preview для Windows 10/11.  
**Browser core:** не поставляется; используется установленный Google Chrome или Microsoft Edge.  
**Совместимость профилей:** формат `nevision-profile-backup-v1`; это первая версия, миграция не требуется.

### Добавлено

- Portable `NeVisionWin.exe`: локальный менеджер отдельных Chromium user-data directories.
- Создание, поиск, группировка, теги, заметки, безопасная чистая копия и локальная история действий для профилей.

### Безопасность

- Proxy-пароли доступны только тому же Windows-пользователю на том же компьютере; после переноса базы их нужно ввести заново.
