Что видит страница

Эта страница показывает обычные параметры, доступные сайту в открытом профиле. Она не ставит оценку «анонимности» и не отправляет полученные через JavaScript параметры на сервер. HTTP-заголовки запрашиваются отдельно по нажатию.

Важно: хостинг уже получает ваш IP при загрузке страницы. Кнопка ниже только показывает адрес, видимый этому серверу; провайдер хостинга может хранить журналы запросов. DNS, WebRTC, UDP и маршрут всего трафика здесь не проверяются.
